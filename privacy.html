Privacidad

Este reproductor usa el reproductor oficial de YouTube para mostrar señales públicas de televisión. Al conectarse y reproducir, YouTube y Google reciben datos técnicos, como la dirección IP, información del dispositivo y datos de reproducción, y pueden usar cookies según sus políticas y los ajustes del navegador.

El código de este proyecto no agrega analítica propia ni solicita contraseñas o acceso a una cuenta. No recibe archivos del USB ni datos de las aplicaciones instaladas en la TV. Los mensajes de control contienen únicamente identificadores públicos de videos, comandos de reproducción y estados técnicos temporales.

El sitio se aloja en GitHub Pages. GitHub informa que registra la dirección IP de las visitas por motivos de seguridad. Los servicios externos aplican sus propias políticas; esta página no controla sus cookies, registros ni opciones de cuenta.

Política de Privacidad de Google · Privacidad de GitHub

Podés consultar las opciones de privacidad y la gestión de tus datos desde tu cuenta de Google. Para dejar de usar este reproductor, cerrá la aplicación; la reproducción integrada se destruye al salir.
